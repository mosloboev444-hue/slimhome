# Материалы для публикации в магазинах (RuStore / Google Play)

## Название
SlimHome

## Краткое описание (до 80 символов)
Лаунчер для Android TV: плитки, погода, без рекламы

## Полное описание

SlimHome — лёгкий лаунчер для ТВ-приставок и Android TV. Заменяет стандартный рабочий стол
на понятный экран: крупные плитки приложений, погода, часы и быстрый доступ к настройкам.

Что умеет:
• Сетка приложений — 3–5 колонок в зависимости от разрешения экрана, рамка обтягивает логотип и название, ровные отступы.
• Погода — город определяется автоматически по IP, показывает температуру и прогноз на несколько дней. Без ключей API и без доступа к геолокации.
• Подсветка фона — фон экрана плавно перекрашивается в цвет выбранного приложения.
• Верхняя панель — сеть (Ethernet/Wi-Fi), часы, дата, кнопки «Настройки» и переход в настройки сети.
• Все приложения — полный список по одной кнопке.
• Адаптивность — проверено на Full HD и на старых телевизорах через композит (576i): ничего не обрезается.

Особенности:
• Размер приложения — 35 КБ.
• Без рекламы, аналитики, аккаунтов и подписок.
• Не требует специальных разрешений, кроме доступа в интернет для погоды.
• Не собирает и не передаёт персональные данные.

Требования: Android TV 8.0 и выше, ARM.

## Что нужно сделать перед публикацией

1. **Подписать release своим ключом** (сейчас стоит debug-подпись, для стора не годится):
   ```bash
   keytool -genkeypair -keystore slimhome.jks -alias slimhome -keyalg RSA -keysize 2048 -validity 10000
   ```
   и прописать `signingConfigs.release` в `app/build.gradle`.
2. Зарегистрировать аккаунт разработчика RuStore (нужна верификация) — https://www.rustore.ru/console
3. Загрузить APK, заполнить карточку по текстам выше, добавить скриншоты.
4. Указать политику конфиденциальности — можно сослаться на этот файл: приложение не собирает данные.

## Политика конфиденциальности (короткий текст)

SlimHome не собирает, не хранит и не передаёт персональные данные. Единственное сетевое обращение —
запрос погоды по IP-адресу к публичным сервисам wttr.in и open-meteo.com. IP-адрес передаётся этим сервисам
в рамках обычного HTTP-запроса и не сохраняется приложением. Приложение не содержит рекламы и аналитики.

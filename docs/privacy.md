# Политика конфиденциальности SlimHome

**Дата:** 4 ноября 2026 г.

Приложение **SlimHome** (лаунчер для Android TV) не собирает, не хранит и не передаёт персональные данные
пользователей.

## Какие данные обрабатываются

- **Погода.** Приложение обращается к публичным сервисам `wttr.in` и `open-meteo.com`, чтобы получить
  температуру для вашего города. Город определяется по IP-адресу через сервис `ip-api.com`.
  IP-адрес передаётся этим сервисам в рамках обычного HTTP-запроса и не сохраняется приложением.
- **Настройки.** Порядок плиток и служебные флаги хранятся локально на устройстве и не покидают его.

## Чего приложение не делает

- не собирает статистику и не использует аналитику;
- не показывает рекламу;
- не запрашивает аккаунт, не требует регистрации и подписки;
- не имеет доступ к контактам, файлам, камере, микрофону и геолокации.

## Разрешения

- `INTERNET` — только для загрузки прогноза погоды;
- `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` — чтобы показать тип подключения в верхней панели;
- `QUERY_ALL_PACKAGES` — чтобы построить список установленных приложений (обязательное требование для лаунчера).

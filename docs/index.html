SlimHome

Лаунчер для Android TV · 35 КБ · без рекламы и аккаунтов
Скачать APK Исходники на GitHub

Плитки приложений

3–5 колонок под экран, рамка по контенту, ровные отступы и фокус с подсветкой.

Погода сама себя находит

Город по IP, прогноз на дни вперёд. Без ключей API и разрешений на геолокацию.

Фон под цвет иконки

При выборе приложения фон плавно перекрашивается в его фирменный цвет.

Работает на старых ТВ

Проверено на 1920×1080 и на 720×576 через «тюльпаны»: ничего не обрезается.

Установка

adb install -r SlimHome-1.0.apk
adb shell cmd package set-home-activity --user 0 com.slimhome.launcher/.MainActivity

Требования: Android TV 8.0+ (API 26), ARM. Вернуть прежний лаунчер можно той же командой с пакетом старого лаунчера.
